# CopyRuUtility — релизы

Этот репозиторий содержит **только готовые сборки** программы CopyRuUtility.

Исходный код лежит в отдельном приватном репозитории и отсюда не виден.

## Зачем отдельный репозиторий

Программа умеет обновлять себя по кнопке «Проверить наличие обновления» в
настройках. GitHub не отдаёт релизы приватного репозитория без авторизации,
а вшивать токен в exe нельзя: его можно извлечь, а токен с правом записи
позволил бы подсунуть обновление сразу всем операторам. Поэтому сборки
выкладываются здесь — в открытом репозитории, который читается анонимно.

## Что здесь лежит

Вложения релизов: `CopyRuUtility.exe` — сборка одним файлом. Именно её
скачивает и устанавливает кнопка «Обновить».

Метка релиза — версия программы: `v1.4.0.0`. Программа сравнивает её со своей
версией и предлагает обновление, если метка новее.

**Черновики программа не видит:** проверка идёт через `/releases/latest`,
который черновики и предварительные версии исключает. Релиз должен быть
опубликован.
